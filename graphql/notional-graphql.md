# Notional Finance GraphQL API

Notional Finance exposes protocol data via GraphQL subgraphs hosted on The Graph protocol. The V2 subgraph covers Ethereum Mainnet fixed-rate lending/borrowing markets, accounts, fCash assets, cash markets, liquidations, and exchange rates. V3 subgraphs (Mainnet and Arbitrum) extend coverage to leveraged vault positions and the V3 protocol upgrade; note that the V3 Studio-hosted endpoints may be deprecated — check the explorer links below for the current deployment.

**Endpoint (V2 Mainnet):** https://api.thegraph.com/subgraphs/name/notional-finance/mainnet-v2
**Endpoint (V3 Mainnet):** https://api.studio.thegraph.com/query/60626/notional-v3-mainnet/v0.0.9
**Endpoint (V3 Arbitrum):** https://api.studio.thegraph.com/query/60626/notional-v3-arbitrum/version/latest
